# صالوناتي كوزمتك - لوحة تحكم صاحب المتجر (Cosmetics Store Owner App)

هذا الملف يوثق تطبيق لوحة تحكم صاحبة/صاحب متجر الكوزمتك (`apps/cosmetics/owner/index.html`) والذي يعمل بتكامل تام مع تطبيق الزبونات (`index.html` و `apps/cosmetics/customer/index.html`).

## مميزات لوحة تحكم التاجر:
1. **إدارة المنتجات والعروض**:
   - إضافة منتجات جديدة مع رفع صور حقيقية من الجهاز (Base64).
   - تحديد السعر بالدينار العراقي والكمية المخزنية والتصنيف (مكياج، عناية بالبشرة، عطور، شعر، إكسسوارات).
   - تعديل وحذف المنتجات بسهولة.
   - إنشاء ونشر العروض الترويجية والخصومات.

2. **إدارة الطلبات**:
   - متابعة طلبات الزبونات الواردة لحظياً.
   - قبول الطلبات وتأكيد التوصيل.

3. **إعدادات المتجر**:
   - تحديث اسم المتجر، المنطقة (مثل الكرادة، المنصور، الجادرية)، رقم الهاتف، والنبذة التعريفية.

4. **التخزين والمزامنة**:
   - يعتمد التطبيق على `localStorage` بمفتاح (`salonati-cosmetics-owner-v2`) لضمان مزامنة المنتجات والعروض المدخلة من قِبل التاجر مع تطبيق الزبونات بشكل فورى.
